# Backend selection

`build` receives the selected target, staged project and output directory and verifies the backend and its Bake checkout. WASM analysis, validation and lowering apply the same Leek source extension as emission before invoking the inherited Bake API. This keeps native platform facts, captures and optional-value handling consistent across commands. Other targets use their selected Bake API directly. C and Rust emission use their respective compiler APIs after successful Bake lowering. The WASM path invokes the pinned Baguette entry point; Baguette performs its own Bake stage exactly once. Its existing numeric ABI restrictions remain in effect until Leek implements the complete OS boundary. The configuration does not claim complete-kernel verification before that boundary exists.
