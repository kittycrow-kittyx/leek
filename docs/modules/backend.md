# Backend selection

`build` receives the selected target and staged project and verifies the backend and its Bake checkout. Analysis and lowering requests use Bake directly. C and Rust emission use their respective compiler APIs after successful Bake lowering. The WASM compilation path invokes the pinned Baguette entry point with Leek's staged userspace project and a non-kernel configuration; Baguette performs its own Bake stage exactly once. This process boundary is an interim integration, not a reusable emitter extension API. Its numeric ABI restrictions remain in effect until Leek implements userspace-specific boundary lowering.
