# WASM source lowering

`lowerWasm(source, checker)` rewrites numeric bitwise expressions, shifts, global Math.imul calls and numeric typed-array for-of declarations. Native width aliases represent i32 and u32. Integer helpers reduce Number operands modulo 2^32 before conversion and restore the signed or unsigned Number result. Multiplication binds the existing Baguette baseline prelude primitive `mulU32`; the TypeScript reference module is checked by Bake but omitted from native emission. The signed result preserves `Math.imul` semantics. Indexed loops evaluate the array expression once and retain loop-local bindings. Built-in array symbols retain their identity when ambient declarations augment the standard library. Explicit typed-array annotations avoid generic buffer types inferred by TypeScript.

`prepareWasmSource(input)` applies the pass to the staged project before Bake. It writes only staged implementation files and the intrinsic reference module when needed, returning that module path for Baguette. The pass leaves BigInt and non-numeric operands alone and rejects unsupported typed-array binding patterns. Reserved width aliases cannot appear in the input. Compound assignments and unary bitwise operations are outside this pass.

Numeric predicates on typed Number operands use the existing `F64.isNaN`, `F64.isFinite`, `F64.isInteger` and `F64.isSafeInteger` primitives in Baguette’s pinned AssemblyScript. The intrinsic reference is checked by Bake and omitted from native emission. Local Number declarations are not rewritten.
